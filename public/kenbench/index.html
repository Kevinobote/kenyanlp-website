How this table works
  • All scores: higher is better ↑. With Above chance selected, 0 means random guessing and 100 is perfect; negative values are worse than guessing.
  • Overall averages the tasks inside each benchmark first, then the benchmarks with equal weight. Rank follows Overall.
  • Task-type and language columns average only the benchmarks that cover them. Hover a column name to see which benchmarks those are.
  • Languages × models lists languages alphabetically and orders models left to right by Overall score, best first. Languages are not ranked, because each one is covered by a different set of benchmarks.

          How to read the scores

          Primary metric. Each benchmark reports one main number, chosen to match how the benchmark's authors report it: accuracy for balanced multiple-choice tasks, weighted F1 for imbalanced classification, span F1 for NER, token F1 for QA, exact match for math, and chrF for translation. All are on a 0–100 scale.

          Above-chance score. Raw scores are not comparable across benchmarks: 33 on a 3-class task is random guessing, while 33 on a 40-class task is strong. The report therefore rescales each score as (score − chance) / (100 − chance) × 100. Zero means random guessing; negative means worse than random. Generative tasks have chance 0, so for them the two views are identical.

          Averaging. Many benchmarks run five prompt templates per language. Tasks are first averaged within a benchmark, then benchmarks are averaged with equal weight, so a benchmark with 40 tasks does not outweigh one with 1.

          One-label runs. If a model gives the same label for every example, accuracy equals that label's share p and weighted F1 equals exactly 2p²/(1+p). Runs matching this identity are flagged. Their scores reflect the label distribution rather than any understanding of the text. Use Hide one-label runs to drop them.

          Uncertainty. Where the harness reports a standard error, ±1.96 × SE approximates a 95% interval. Differences of 1–2 points between models on a single task are usually inside that interval.
